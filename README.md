# HandHopHop

Android-приложение, где можно выбрать изображение из онлайн-ленты или галереи и превратить его в **схему для рукоделия**.

## Возможности

- **Главный экран**
    - показывает выбранный проект/изображение
    - быстрый переход к статистике и к экрану работы со схемой

- **Онлайн схемы**
    - лента изображений в стиле **Pinterest**
    - бесконечная подгрузка (если эти ресурсы существуют)

- **Схема**
    - выбранное изображение автоматически преобразуется в **сетку по номерам**
    - минимальная сторона сетки — **128 клеток**, либо произвольное
    - поддерживаются **zoom/pan**

- **Профиль**
    - редактирование данных профиля
    - выбор аватара из галереи

## Как пользоваться (в процессе доработок)

1. Перейди в **Онлайн схемы**
2. Нажми на картинку — она станет выбранной схемой
3. На главном экране нажми **Начать** — откроется экран схемы с “раскраской по номерам”

## Примечания

- Источник изображений — API `nekos-api` (фильтрация по `rating == safe` реализована на стороне репозитория).
