# HandHopHop

**HandHopHop** — Android-приложение, которое помогает превратить изображение из онлайн-ленты или галереи в **схему для рукоделия**.

Приложение позволяет выбрать картинку, подготовить её для работы и получить сетку, удобную для дальнейшего использования как шаблона.

## Что умеет приложение

### Онлайн-лента
- показ изображений в формате визуальной ленты
- загрузка изображений из внешнего API
- выбор изображения для дальнейшей работы

### Создание схемы
- преобразование выбранного изображения в сетку по номерам
- генерация схемы с минимальной стороной от `128` клеток
- поддержка масштабирования и перемещения изображения

### Профиль
- просмотр и редактирование профиля
- выбор аватара из галереи

### Главный экран
- отображение текущего выбранного проекта
- быстрый переход к экрану схемы и связанным разделам

## Архитектура проекта

Проект построен как **многомодульное Android-приложение**.

### Core-модули
- `core/design` — общие UI-компоненты и Compose-элементы
- `core/network` — сетевой слой, API и инфраструктура запросов
- `core/session` — данные и логика, связанные с пользовательской сессией

### Feature-модули
- `feature/feed` — экран онлайн-ленты
- `feature/mash` — генерация и работа со схемой
- `feature/bookmark` — сохранённые элементы
- `feature/settings` — экран настроек пользователя

### App-модуль
- `app` — точка входа, навигация, тема приложения и объединение всех модулей

## Технологии

- Kotlin
- Jetpack Compose
- Android Gradle Kotlin DSL
- Retrofit
- OkHttp
- Coil
- Kotlin Coroutines

## Как запустить

Из корня проекта:

```bash
./gradlew assembleDebug
```

Для запуска тестов:

```bash
./gradlew testDebugUnitTest
```

## Как использовать

1. Открой экран онлайн-ленты.
2. Выбери изображение из ленты или используй локальную картинку.
3. Перейди к экрану схемы.
4. Сгенерируй и настрой схему для рукоделия.

## Источник данных

Для загрузки изображений используется внешний API. Фильтрация безопасного контента выполняется на стороне репозитория данных.
