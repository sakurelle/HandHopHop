# HandHopHop

**HandHopHop** — Android-приложение для создания схем для рукоделия по изображениям. Пользователь может выбрать изображение из онлайн-ленты или локальной галереи, настроить параметры будущей схемы, выполнять работу по клеткам и сохранять прогресс.

Проект ориентирован на сценарий, в котором изображение превращается в удобную сетку по номерам. Приложение хранит созданные работы, показывает прогресс, позволяет возвращаться к незавершённым схемам, работать с избранным и смотреть статистику по текущему проекту.

## Основные возможности

### Онлайн-лента

- просмотр изображений в формате визуальной ленты;
- загрузка изображений из внешнего API;
- фильтрация изображений по ориентации, цвету и категории;
- блок рекомендованных изображений;
- добавление изображений в избранное;
- отображение статуса начатой работы и процента выполнения прямо в ленте;

### Локальные изображения

- выбор изображения из галереи устройства;
- создание схемы на основе локальной картинки;

### Создание схемы

- создание проекта по изображению из ленты или галереи;
- название проекта;
- настройка количества цветов;
- выбор сложности схемы;
- формирование палитры ниток на основе DMC-цветов;

### Работа со схемой

- интерактивное выполнение схемы по клеткам;
- отметка выполненных клеток;
- выделение выбранного цвета на схеме;
- управление состоянием цветов в палитре;
- автоматическое сохранение прогресса;
- восстановление сохранённой работы после выхода из приложения;
- экспорт схемы в PDF;

### Завершение работы

- отдельный экран после полного выполнения схемы;
- возможность вернуться к завершённой схеме;
- возможность сохранить результат в PDF;
- переход к рекомендациям для выбора новой схемы.

### Сохранённые элементы и избранное

Экран сохранённых элементов объединяет изображения и работы, с которыми пользователь уже взаимодействовал.

Поддерживаются фильтры:

- **Все** — избранные изображения и начатые работы;
- **Избранное** — изображения, явно добавленные пользователем;
- **Работы** — начатые проекты с сохранённым прогрессом.

Для элементов отображаются превью, состояние избранного и прогресс выполнения, если по изображению уже была создана работа.

### Статистика проекта

- отображение названия и типа текущего проекта;
- количество выполненных и оставшихся клеток;
- статистика по использованным цветам;
- время работы за текущий день;
- активность за неделю.

### Настройки

- переключение светлой и тёмной темы (а также возможность следовать системной теме устройства);
- просмотр занятого приложением хранилища;
- очистка локальных данных;
- работа с премиум-доступом через ваучер.

## Архитектура

Проект построен как многомодульное Android-приложение.

### App-модуль

- `app` — точка входа в приложение, навигация, подключение основных экранов и общей темы.

### Feature-модули

- `feature/feed` — онлайн-лента, фильтры, рекомендации, состояние избранного и начатых работ;
- `feature/mash` — создание схемы, рабочий экран, сохранение прогресса, статистика и завершение работы;
- `feature/bookmark` — экран сохранённых элементов, избранного и начатых работ;
- `feature/settings` — настройки темы, памяти, очистки данных и премиум-доступа.

### Core-модули

- `core/design` — дизайн-система, цвета, размеры, общие UI-компоненты и тема приложения;
- `core/network` — сетевой слой и получение изображений для онлайн-ленты;
- `core/session` — состояние пользовательской сессии и премиум-логика;
- `core/system` — локальное хранение данных, Room Database и репозитории для работы с сохранёнными проектами.

## Хранение данных

Для локального хранения используется Room. В базе сохраняются данные о созданных работах, параметрах схемы, прогрессе выполнения, избранном, локальных путях изображений и статистике активности.

Изображения из локальной галереи не хранятся в базе как `ByteArray`/BLOB. После выбора они копируются во внутреннее хранилище приложения, а в базе сохраняется путь к файлу. Такой подход уменьшает размер строк в базе и позволяет безопасно переоткрывать локальные работы без повторного доступа к исходной картинке из галереи.

## Работа с изображениями

Приложение поддерживает два источника изображений:

1. **Онлайн-изображения** — загружаются из внешнего API и используются по URL.
2. **Локальные изображения** — выбираются из галереи, копируются во внутреннее хранилище приложения и далее используются по локальному пути.

Для отображения превью используется единая логика: если у работы есть локальный `imagePath`, приложение использует локальный файл; если локального пути нет, используется онлайн-URL; если источник недоступен, отображается заглушка.

## Прогресс работы

Прогресс схемы сохраняется локально. Для работы фиксируются параметры проекта, выбранное изображение, завершённые клетки, процент выполнения и время активности. Это позволяет продолжить работу после закрытия приложения и отображать состояние проекта на экранах ленты, работы и сохранённых элементов.

## Экспорт

Готовую или текущую схему можно экспортировать в PDF. После сохранения приложение показывает сообщение о результате операции и может отправить системное уведомление, если разрешение на уведомления уже выдано.
